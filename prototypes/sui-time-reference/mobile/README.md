# 移动端原型

本目录是岁岁时光移动端（优先安卓）的交互原型。**已由生产移动端 `uni-client/` 实现**，本目录保留为交互参考稿，与桌面原型同级，复用 `../shared/data.js` 的业务语义与 `../shared/tokens.css` 的设计变量。

## 入口

直接用浏览器打开 `index.html`，建议使用移动视口（如 390×844）验收。

## 页面与弹层

| 类型 | 名称 | 入口/动作 | 主要状态 |
| --- | --- | --- | --- |
| 主视图 | 事项 | 底部 Tab「事项」 | 分类筛选、今天/7天内/稍后分组、完成切换、空列表 |
| 主视图 | 规划（我的一月） | 底部 Tab「规划」 | 上下月、月历事项、溢出数量、点击日期新建 |
| 主视图 | 我的 | 底部 Tab「我的」 | 资料卡、隐藏完成开关、恢复演示数据 |
| 底部弹层 | 事项编辑 | 悬浮 + 或事项条目 | 新增、编辑、删除、校验失败、优先级/分类/重复/子任务/备注 |
| 底部弹层 | 检查更新 | 我的 → 检查更新 | 已是最新、发现新版本、下载中（均为界面示意） |

## 说明

- 检查更新为纯界面示意，不真实下载安装；真实能力需接入原生更新服务。
- 数据持久化写入 `localStorage` 的 `sui-time-reference:v1`，与桌面原型共用键。
- 本原型不代表移动客户端已发布，仅为需求与交互参考。
