# 已完成待办样式与周视图高度优化

## 目标

增强已完成待办的视觉辨识度，并让“我的一周”网格充分利用桌面窗口的可用高度，减少页面底部无意义空白。

## 范围

- 本期包含：全部事项、我的一周、我的一月展示态标题的淡删除线；周网格的自适应高度。
- 本期不包含：编辑弹窗和子事项输入样式、完成状态逻辑、数据结构、原生接口和月视图高度。

## 用户流程

1. 用户打开已开启“显示已完成”的全部事项、周视图或月视图。
2. 已完成待办保留原有淡化效果，标题额外显示淡删除线；图标和时间不显示删除线。
3. 用户打开“我的一周”时，周网格填满周期工具栏下方的剩余空间；窗口高度不足时页面继续滚动。

## 业务规则

- 删除线仅依据现有 `done` 展示状态，不增加新的状态或判断逻辑。
- 删除线仅作用于展示态标题，编辑态文字保持正常，避免影响输入可读性。
- 周网格保留 540px 最小高度和现有页面边距，不压缩日期列和任务卡片。

## 接口契约

无接口变化。

## 数据结构

无 TypeScript、Rust、SQLite 或持久化数据变化。

## 异常与边界

- 未完成待办不得出现删除线。
- 月视图中的完成图标和计划时间不得继承删除线。
- 小窗口下允许页面滚动，不得产生内容遮挡、布局跳动或不可点击区域。

## 验收条件

- [x] 全部事项、我的一周、我的一月中的已完成标题均显示淡删除线。
- [x] 未完成标题、完成图标、计划时间和编辑态输入文字不显示删除线。
- [x] 周网格在较高窗口中填满页面剩余高度，在较小窗口中保持至少 540px 并可滚动。
- [x] 显示或隐藏已完成、事项点击和拖动行为保持不变。
- [x] 前端构建、隔离浏览器多尺寸验收和 `git diff --check` 通过。

## 实现证据

- 展示结构与样式：`desktop-client/src/App.vue` 为周页面增加独立布局类、为月视图标题增加文本容器；`desktop-client/src/styles/app.css` 增加完成态标题删除线和周网格自适应规则。
- 静态验证：`desktop-client` 的 `npm run build` 通过，`vue-tsc --noEmit` 和 Vite 生产构建均成功；`git diff --check` 通过。
- 浏览器验收：独立 Playwright Chromium 在 `1100 x 720`、`1440 x 900`、`1920 x 1080` 下通过。周网格高度分别为 540px、717px、897px；大窗口底部间距为 28px，所有尺寸页面级横向溢出均为 0。
- 交互回归：已完成标题计算样式为 `line-through`，时间和编辑态输入为 `none`；显示/隐藏已完成、事项打开和跨日期拖放均正常；控制台 0 错误、0 警告。
